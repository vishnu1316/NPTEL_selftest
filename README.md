# NPTEL Self-Test (Weeks 1 to 12)

Plain HTML + CSS + JavaScript. No installation or internet needed.

## Run in VS Code
1. Unzip `nptel-quiz.zip`.
2. VS Code > File > Open Folder > choose the `nptel-quiz` folder.
3. Install the "Live Server" extension (Ritwick Dey).
4. Right-click `index.html` > "Open with Live Server".
   (Or simply double-click `index.html` to open it in a browser.)

## How it works
- Pick one option, then press Submit: correct = green, wrong = red and the right answer turns green.
- Reset clears that question so you can change your option.
- 1 mark per correct answer, 120 questions, pass mark 40.
- "Show result" gives the total marks and PASS/FAIL. "Reset all" starts over.
